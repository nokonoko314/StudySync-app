StudySync

プライバシーポリシー

制定日・最終更新日: 2026年10月1日

StudySync(以下「本アプリ」)の開発者(以下「当方」)は、本アプリの利用者の情報を、以下のとおり取り扱います。

1. 取得する情報

(1) Googleアカウントの情報

Googleアカウントでログインしたときに、氏名(表示名)、メールアドレス、利用者を識別するID(Firebase の利用者ID)を取得します。

(2) 学習データ

本アプリで作成したタスク、教科、プロジェクト、勉強時間などの記録、アプリの設定を取得します。これらは端末内に保存され、ログインしている場合はクラウド(Google Firebase の Cloud Firestore)にも保存されます。

(3) Googleカレンダーのデータ(連携した場合のみ)

「Googleカレンダー同期」を有効にした場合、Googleカレンダーの一覧と、予定のタイトル・日時を読み取ります。読み取った予定は本アプリの画面に表示するために端末内にだけ保存し、当方のサーバーには送信しません。

「StudySyncの予定を書き出す」を有効にした場合は、利用者のGoogleカレンダーに「StudySync」という名前のカレンダーを作成し、本アプリの時間軸に置いたタスク(タイトル・日時・教科名)をそこに書き込みます。本アプリが作成したカレンダー以外の予定を変更・削除することはありません。

(4) 購入に関する情報

有料プラン(StudySync プレミアム)を購入した場合、購入の状態(プラン、有効期限など)を、課金管理サービス RevenueCat を通じて取得します。購入は利用者ID にひもづけて管理します。クレジットカード番号などの支払い情報は Google Play が取り扱い、当方は取得しません。

(5) 広告に関する情報

本アプリが広告を表示する場合、広告配信サービス Google AdMob が、広告ID などの端末の識別子や、おおよその利用状況を取得することがあります。取得される情報と利用目的は、Google のポリシーに従います。

(6) 端末内でのみ使う情報

通知の予約、ホーム画面ウィジェットに表示する予定などは、端末内でのみ使用し、外部には送信しません。

2. 利用目的

  • 本アプリの機能(学習計画、忘却曲線にもとづく復習、統計、ウィジェット、通知)を提供するため
  • データをクラウドに保存し、機種変更やほかの端末でも同じデータを使えるようにするため
  • Googleカレンダーの予定を表示し、希望する利用者の予定を書き出すため
  • 有料プランの購入状態を確認し、機能を提供するため
  • お問い合わせへの対応、不具合の調査、本アプリの改善のため

3. 第三者への提供

当方は、法令にもとづく場合を除き、利用者の情報を第三者に販売・提供しません。本アプリは、機能の提供のために次の外部サービスを利用しており、それぞれのサービスが情報を取り扱います。

  • Google Firebase(ログイン、クラウド保存) — プライバシーとセキュリティ
  • Google カレンダー API(カレンダー同期) — Google プライバシーポリシー
  • Google Play(アプリの配布、購入の決済) — Google プライバシーポリシー
  • RevenueCat(購入状態の管理) — RevenueCat Privacy Policy
  • Google AdMob(広告の配信) — Google の広告に関するポリシー

4. Google API から取得した情報の取り扱い

本アプリが Google API から受け取った情報の利用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。Googleカレンダーのデータを、広告、販売、AI モデルの学習などの目的に使用することはありません。

StudySync's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. 保存期間と削除

クラウドに保存した情報は、利用者がアカウントを削除するまで保存します。利用者は、本アプリの「設定 → Googleアカウント連携 → アカウントとデータを削除」から、いつでもアカウントとクラウドのデータを削除できます。詳しくはアカウントとデータの削除をご覧ください。

Googleカレンダーへのアクセスは、本アプリの「設定 → Googleカレンダー同期 → 連携を解除」で停止できます。許可そのものの取り消しは、Google アカウントの「サードパーティ製のアプリとサービス」から行えます。

6. 安全管理

クラウドのデータは、本人のアカウントからしか読み書きできないように設定しています。通信は暗号化(HTTPS)されます。

7. 13歳未満の方の利用

13歳未満の方は、保護者の方の同意を得てからご利用ください。

8. このポリシーの変更

本ポリシーは、必要に応じて変更することがあります。重要な変更がある場合は、本アプリまたはこのページでお知らせします。
