# StudySync 要件定義書

- 版: 1.0(2026-09-29)
- 対象: モックアップ `mockup.html`(Artifact版 v9)で合意した UI/UX を正式アプリ `app/` に反映するための要件
- 関連: [02_ギャップ分析.md](02_ギャップ分析.md) / [03_詳細設計書.md](03_詳細設計書.md)

## 1. 目的と対象ユーザー

| 項目 | 内容 |
|---|---|
| 目的 | 学生が「いつ・何を勉強するか」を時間軸で計画し、実際に計測した時間を記録して振り返れるようにする |
| 主な利用者 | 中高生・大学生・資格学習者(1人で使う) |
| 利用端末 | Android スマホ(主)、iPad/Android タブレット(副) |
| 利用シーン | 朝や前日夜に予定を組む → 勉強中に計測 → 夜にカレンダーで振り返る |

## 2. 用語

| 用語 | 意味 |
|---|---|
| タスク | 勉強の1単位。タイトル・教科を持つ |
| 未設定タスク(プール) | まだ時間軸に置いていないタスク |
| 配置済みタスク | 時間軸上に開始時刻と長さを持つタスク |
| 計測 | タスクの実施時間をリアルタイムに記録すること |
| プログラム | 複数日にまたがる期間(例: 期末試験、英検対策)。旧称「プロジェクト」 |
| 教科 | タスクの分類。色を持つ |

## 3. 機能要件

優先度: **Must** = 初回リリースに必須 / **Should** = できれば初回 / **Could** = 後回し可

### 3.1 ホーム(タイムライン)

| ID | 要件 | 優先度 |
|---|---|---|
| F-H01 | 1日を 0:00〜24:00 の縦の時間軸で表示し、現在時刻の赤線を画面の約1/3の高さに固定して自動追従する | Must |
| F-H02 | 手でスクロールしたら追従を止め、「現在時刻へ戻る」ボタンで復帰できる | Must |
| F-H03 | 未設定タスクを時間軸へドラッグして配置できる(スナップなし、分単位) | Must |
| F-H04 | 配置済みタスクを上下ドラッグで移動、下端ドラッグで長さを変更できる | Must |
| F-H05 | 配置済みタスクを未設定へドラッグ、または編集画面のボタンで未設定に戻せる | Must |
| F-H06 | タスクの計測を開始・停止できる。計測中は予定枠(ゴースト)を薄く表示する | Must |
| F-H07 | 計測が予定より延びた場合、停止時に後続の予定タスクを自動で後ろへずらす(ラバーバンド) | Must |
| F-H08 | 右スワイプで完了(未計測)、左スワイプで削除できる。同じ操作をボタンでも行える | Must |
| F-H09 | 完了・削除・未設定に戻す・計測停止の直後に「元に戻す」を表示する(5秒) | Must |
| F-H10 | 完了済みタスクを編集画面から「未完了に戻す」ことができる | Must |
| F-H11 | 週(月〜日)を表示し、左右スワイプと ‹ › ボタンで前後の週に切り替えられる | Must |
| F-H12 | 今日以外を表示中は「今日」ボタンで今日に戻れる | Must |
| F-H13 | 週の下にプログラムの期間バーを表示し、期間中の日は「n/m日目」を表示する | Must |
| F-H14 | プログラムの期間バーをタップすると、プログラム詳細を開く | Must |
| F-H15 | 予定開始の数分前に通知バナーを表示し、スヌーズできる | Should |
| F-H16 | 前日に終わらなかったタスクを今日へ自動で繰り越す(元に戻せる) | Should |
| F-H17 | 各日付の下に、その日に計測した合計時間を表示する | Should |

### 3.2 タスクの作成・編集

| ID | 要件 | 優先度 |
|---|---|---|
| F-T01 | 下から出るシートでタイトルと教科を入力してタスクを作る | Must |
| F-T02 | 教科チップの並びの最後の入力欄から、その場で新しい教科を追加できる(1タップで入力開始、決定ボタン不要) | Must |
| F-T03 | 編集では、タイトル・教科・開始時刻・所要時間を変更できる | Must |
| F-T04 | 編集画面に「未設定に戻す」「完了にする」「未完了に戻す」「削除」を状態に応じて表示する | Must |
| F-T05 | 主な操作ボタンは1画面に1つ(下部の大きなボタン)とする | Must |
| F-T06 | 入力途中でシートを閉じようとしたら破棄の確認を出す | Must |
| F-T07 | タイトル未入力のときは入力欄の下にエラーを表示する | Must |
| F-T08 | 日本語入力の変換確定の Enter で送信しない | Must |

### 3.3 カレンダー

| ID | 要件 | 優先度 |
|---|---|---|
| F-C01 | 月表示・週表示を切り替えられる | Must |
| F-C02 | 日付をタップしても画面遷移せず、下部にその日の詳細(合計時間・教科別の内訳・タスク一覧)を表示する | Must |
| F-C03 | 詳細の「この日のタイムラインを開く」でホームのその日へ移動する | Must |
| F-C04 | タスク・外部予定・プログラムを形と色で区別して表示する | Must |
| F-C05 | Google カレンダーの予定を読み込んで表示する | Could |

### 3.4 プログラム

| ID | 要件 | 優先度 |
|---|---|---|
| F-P01 | 名前・色・開始日・終了日を持つプログラムを作成・編集できる | Must |
| F-P02 | 詳細画面に、期間・経過日数・合計時間・1日平均・完了タスク数を表示する | Must |
| F-P03 | 詳細画面に期間中のカレンダーを表示し、勉強時間が長い日ほど濃く塗る | Must |
| F-P04 | 期間中の教科別の内訳と、選んだ日のタスク一覧を表示する | Must |

### 3.5 統計・教科・設定

| ID | 要件 | 優先度 |
|---|---|---|
| F-S01 | 週・月の合計時間、教科別の割合、週の目標に対する達成率を表示する | Must |
| F-S02 | 教科の追加・名前変更・色変更・アーカイブができる | Must |
| F-S03 | テーマ(ライト/ダーク/端末に合わせる)を切り替えられる | Must |
| F-S04 | 復習の自動作成(忘却曲線: 1,3,7,14,30日)を使える ※既存機能を維持 | Should |

## 4. 非機能要件

| ID | 分類 | 要件 |
|---|---|---|
| N-01 | 対応端末 | Android 8.0(API 26)以上。タブレットでも崩れない |
| N-02 | 性能 | タップへの反応は 100ms 以内。ドラッグ中は 60fps を保つ |
| N-03 | オフライン | 通信がなくても全機能が使え、つながったら同期する |
| N-04 | データ保全 | 端末内に保存し、ログイン時は Firebase と同期する。アプリを閉じてもデータが消えない |
| N-05 | 操作の安全性 | 破壊的な操作(削除・完了・未設定に戻す)はすべて元に戻せる |
| N-06 | アクセシビリティ | 文字と背景のコントラスト 4.5:1 以上、タッチ領域 44px 以上、ジェスチャー操作には必ずボタンの代替を用意、「視差効果を減らす」設定を尊重 |
| N-07 | ジェスチャー | ドラッグが中断(pointercancel)された場合は元の位置に戻し、他のタスクに影響させない |
| N-08 | 見た目 | ダーク: スレート×シルバー、ライト: 透明感のある水色を基調とし、全画面で同じトークン(色・角丸・影)を使う |
| N-09 | セキュリティ | 認証は Firebase Authentication(Google)。Firestore のルールで本人のデータ以外は読み書き不可 |
| N-10 | 配布 | 当面はデバッグ APK を直接配布。正式公開時は署名済み AAB を Google Play へ |

## 5. 対象外(今回はやらない)

- 複数人での共有・グループ学習
- iOS ネイティブ版(iPad はブラウザ版で確認)
- 課金・広告
